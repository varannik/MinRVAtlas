# dMRV web

Next.js operator UI: 3D control room (`/`) and Quality Console (`/quality`).

Run from the **repo root**: `npm run dev`. Env file: `.env.local` in this directory (see `.env.example`).

Stack: Next 16, React 19, R3F, Zustand, Tailwind 4. BFF under `src/app/api/`. R3F stays in `src/components/scene/` — not on `/quality`.

# 3DMinRV — agent notes

Directory monorepo. Next.js is **not** at the repo root.

- **Web:** `apps/web/` — Next.js 16 App Router, React 19. Read `apps/web/node_modules/next/dist/docs/` before writing routes. `params` is a `Promise`. Route handlers live in `apps/web/src/app/api/.../route.ts`. `export const dynamic = "force-dynamic"` on those routes. `next dev` may rewrite `apps/web/AGENTS.md`.
- **Atlas data:** the web gets every project, 3D site model, practice journey and demo MRV history from the backend (`/api/atlas/*`, DynamoDB + S3, `apps/web/src/lib/atlas/`). Nothing is bundled and nothing is kept in browser storage. Demo data lives in `apps/web/seed/` (`npm run backend:up && npm run seed` locally; sources in `apps/web/scripts/seed/sources/`). Real monitoring data comes in from a project's live dashboard → Load data (`/projects/[id]/data`, `/api/monitoring/*`): a site spreadsheet, through the project's tag map approved by a platform admin, into the stream bucket (`<tenant>/<registry>/<project>/dt=…`), which the calculation tree and the quality engine both read in place of the seed. A load can be removed again (its rows only, with a reason on its record). `apps/web/src/legacy/` is the old project page, frozen and unreachable.
- **Sentinel:** `apps/sentinel/` — FastAPI + Celery, being retired. Its data quality checks have moved to the quality engine, and its data quality console pages are gone: `/quality/vv` and `/quality/protocols` (route group `app/quality/(vv)`) are all that is left of its console, and the proxy allowlist is `v2/vv` and `v2/protocols`. V&V, the reviewer and the protocol registry stay until they have a home. Do not copy Python engines into Next. Do not add a Sentinel UI.
- **Quality engine:** `apps/quality-engine/` — Python, standard library only (the summary step adds the Anthropic SDK layer), run as Lambda steps by `infra/lib/quality/` (its own stack on Cortex's rails: tenant session, event bus, gateway tool `quality___findings`). Checks and detectors set the verdict; `text.py` words every finding; Claude only writes an optional run summary for operators, after the verdict, and never sets it. Web: `/quality` (the data quality page: findings, coverage, runs, decisions, rules and tag map), `/api/data-quality/*`, the calculation tree's trend, the journey's period details and Monitor tasks; registry writes of data need the engine not to block the period (`lib/quality/gate.ts`). Runs reach the Cortex graph through `QualityRunCompleted`. `make quality-test`.
- **Cortex agent:** `apps/cortex-agent/` — LangGraph agent on AgentCore Runtime (linux/arm64). Claude via the Anthropic SDK's Bedrock client, EU inference profile. The web reaches it only through `/api/cortex/ask` with the user's Cognito token.
- **Infra:** `infra/` — CDK eu-west-2. Every `make` target lives in `infra/Makefile` (deploy, pipeline-start, seed, logs, …); run them in `infra/`. There is no root Makefile. Images: `apps/web/Dockerfile` and `apps/sentinel/backend/Dockerfile`. App releases: AWS CodePipeline (`docs/cicd.md`), not GitHub Actions.

Identity: `x-tenant-id: fourfourone`. Local Sentinel token: `local-sentinel-m2m-token`.
